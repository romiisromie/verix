# Verix

**Платформа цифровой репутации для школьников в IT**

Докажи навыки с AI, находи стажировки и гранты, прокачивайся по личному роадмапу.

[Открыть Verix](https://verix-khaki.vercel.app) · [зеркало на GitHub Pages](https://romiisromie.github.io/verix/) (без AI)

## Возможности

- **Профиль** — репутационный скор, навыки, XP и уровень, серия дней, челленджи недели, достижения. Редактирование, сохранение в PDF, «Поделиться».
- **SkillProof** — даёшь ссылку на публичный GitHub-репозиторий и/или описание проекта. AI смотрит на код, README и историю коммитов и ставит общий балл, оригинальность, сложность и уровень. Навык попадает в профиль с отметкой «код ✓».
- **TalentMatch** — стажировки, гранты, хакатоны и конкурсы из `data/opportunities.json`. Совпадение считается по профилю и проверенным навыкам; фильтры по типу, городу и классу; дедлайны. Карточки свайпаются, заявку можно написать прямо в приложении.
- **Рейтинги** — ученики, школы, навыки и соревнования; профили учеников и чат.
- **EduPath** — личный роадмап: AI строит 4 фазы под цель, класс, часы в неделю и навыки. Задачи отмечаются, прогресс считается сам.

### Как устроены XP

| Действие | XP |
|---|---|
| Зайти в день | 5 |
| Проверка в SkillProof / по коду GitHub | 20 / 40 |
| Добавить навык в профиль | 15 |
| Отклик / заявка | 5 / 25 |
| Задача / фаза роадмапа | 10 / 30 |
| Челлендж недели | 50 |

Уровень: 40 XP до 2-го, дальше порог растёт квадратично (LVL 5 — 640 XP). XP за задачу и фазу начисляются один раз.

## Технически

| Что | Как |
|---|---|
| Фронтенд | HTML + CSS + чистый JavaScript, без сборки |
| AI | Groq API (`openai/gpt-oss-120b`, бесплатный тариф) через серверные функции `/api/skillproof` и `/api/roadmap` — ключ не попадает в браузер |
| GitHub | Публичный GitHub API: дерево файлов, языки, коммиты, README и пара ключевых файлов |
| Хранение | `localStorage`: аккаунт, профиль, навыки, матчи, заявки, переписка, роадмап, XP |
| PWA | Манифест, иконки, service worker, работа офлайн, установка на телефон |
| Доступность | Управление с клавиатуры, роли и подписи для скринридеров, фокус в модальных окнах, Esc, `prefers-reduced-motion` |
| SEO | Описание, Open Graph-превью, JSON-LD, `robots.txt`, `sitemap.xml` |
| Безопасность | Экранирование пользовательского ввода, CSP и защитные заголовки, лимит запросов к AI |

## Вход

Сервера с аккаунтами пока нет. Можно войти с любым email и паролем от 6 символов: аккаунт создаётся автоматически и хранится только в этом браузере (пароль хранится как хеш SHA-256). Кнопка «Попробовать без регистрации» открывает демо-режим.

## Запуск локально

```bash
git clone https://github.com/romiisromie/verix.git
cd verix
npm start
```

Откройте http://localhost:8000. Без сервера AI SkillProof показывает предварительную оценку и честно подписывает её так.

## Настоящая AI-оценка (бесплатно, через Groq)

1. Получите бесплатный ключ на [console.groq.com/keys](https://console.groq.com/keys).
2. Добавьте его в Vercel и задеплойте:

```bash
npx vercel env add GROQ_API_KEY production
npx vercel --prod
```

После этого `POST /api/skillproof` вызывает модель и возвращает оценку в строгом JSON. Если функция недоступна (например, на GitHub Pages) или кончился бесплатный лимит, приложение переключается на предварительную оценку. Модель можно сменить переменной `GROQ_MODEL`.

Для Netlify: подключите репозиторий и добавьте ту же переменную `GROQ_API_KEY`.

**GitHub-проверка** работает без настроек, но без токена GitHub даёт 60 запросов в час на сервер (примерно 12 проверок). Чтобы поднять лимит до 5000, создайте [fine-grained token](https://github.com/settings/personal-access-tokens/new) без дополнительных прав и добавьте его:

```bash
npx vercel env add GITHUB_TOKEN production
```

## Возможности TalentMatch

Список лежит в `data/opportunities.json`. Сейчас там примерные данные для демо — замените их на реальные. Поля: `type`, `org`, `title`, `city`, `grades` (диапазон классов, 12+ — студенты), `deadline` (`YYYY-MM-DD` или `null`), `skills` (по ним считается совпадение), `tags`, `desc`, `url`. Прошедшие дедлайны скрываются сами.

## Исследование надёжности SkillProof

В папке `research/` — открытый и повторяемый эксперимент: можно ли доверять AI-оценке навыка по коду.

```bash
node research/build-sample.mjs        # выборка репозиториев трёх уровней + объективные метрики по git-истории
node research/eval-skillproof.mjs     # прогоны через рабочий API (3 повтора + тесты на обман)
pip install scipy matplotlib && python research/analyze.py   # статистика и графики
```

Сырые данные — `research/data/`, графики — `research/fig/`. Автотесты сервера: `npm test`.
